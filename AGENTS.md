# IslandMed AI

IslandMed is an AI-native multilingual healthcare companion focused on helping foreigners navigate healthcare situations in Asia.

The product is NOT an AI doctor.

It should behave like:
- a calm medical concierge
- a multilingual healthcare guide
- a trustworthy AI companion

Current stage:
We are ONLY building LOOP 1.

LOOP 1:
User describes symptoms →
AI asks follow-up questions →
AI provides basic guidance →
AI recommends next steps.

Core principles:
- reduce anxiety
- conversational clarity
- mobile-first
- multilingual support
- maintainable architecture
- minimalism over complexity

Tech stack:
- Next.js
- React
- Tailwind
- Supabase
- DeepSeek / OpenAI APIs

Important constraints:
- Do NOT overengineer
- Do NOT build multi-agent systems yet
- Do NOT add unnecessary abstractions
- Focus on conversational quality
- Focus on clean architecture
